# Terso 0.1.0

_Released 2026-09-28. The first release._

Terso is a local-first writing instrument for macOS. It is a quiet Markdown editor
first, with deterministic writing analysis, statistical style analysis, and an
optional AI assistant that can only propose changes. Everything works with no
network, no API key and no AI model.

## ✨ New features

- **Markdown editor** for `.md`, `.markdown`, `.tex` and `.txt`, with documents
  sharing one window through in-window tabs, each with its own editor state and
  undo history.
- **Source, Mixed and Full rendering modes.** Mixed styles Markdown in place and
  shows its source on the line you are editing. Full renders the whole document.
  Markdown parsing and HTML sanitization are bundled for offline previews (#2) @lalmei
- **Local writing analysis**: sentence difficulty, passive voice, adverbs,
  qualifiers, filler, complex words, repeated words and phrases, rhythm,
  paragraph length and document statistics.
- **Statistical style analysis** against human reference bands per writing
  domain, with an AI-style signal level and specificity analysis.
- **Science sidebar** with bundled KaTeX for offline LaTeX typesetting. Notation,
  quantities and claims are listed, and each row jumps straight to its place in
  the text (#1) @lalmei
- **Offline alternatives** from a bundled, licensed WordNet thesaurus, keeping
  WordNet's meaning order, with replacement of a single occurrence and a simpler
  picker.
- **Optional AI assistant** using Apple's on-device model by default, or Codex
  and Claude Code CLIs, OpenAI, Anthropic and OpenAI-compatible local servers
  (Ollama, LM Studio, llama.cpp). It only proposes revisions. Each one is
  anchored to an exact passage and goes through a review gate that refuses
  stale or ambiguous edits.

## 🐛 Fixes

- Opening a document joins the existing native tab group, and tabs stay inside
  one window for tiling window managers.
- Rendered math and links are kept while typing.
- Styled Markdown source stays visible in Mixed mode.
- Rendered math reserves line height, so it no longer overlaps nearby lines.
- Notation introduced by prose and by symbol lists is recognized.
- The sidebar toggle stays fixed at the top left.
- Source metadata keeps compact line spacing.

## Install

Download the `.dmg` from the
[release page](https://github.com/Terreaux/terso/releases/tag/v0.1.0), open it and
drag Terso into Applications. Requires Apple silicon and macOS 15 or later. The
app is ad-hoc signed, not notarized: approve it once in System Settings →
Privacy & Security.
